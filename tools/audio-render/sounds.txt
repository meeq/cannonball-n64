# Sound IDs to bake into the N64 wav64 payload.
#
# Consumed by cmake/audio-payload.cmake — each row becomes one .wav64 in the
# build tree, dropped into the DFS at ROM-build time.
#
# Columns: id  kind            filename            params
#   id        Z80 sound command byte from src/main/engine/audio/commands.hpp
#   kind      music_loop:    PCM+YM mix; wav64 wraps from end back to `intro`
#             music_oneshot: PCM+YM mix; wav64 plays once and stops
#             fx:            YM-only;    wav64 plays once and stops
#   filename  output basename under audio/raw and audio/wav64
#   params    music_loop:    intro_seconds  loop_seconds
#             other kinds:   duration_seconds
#
# Loop selection methodology:
#
# Loop points were chosen empirically: candidate (intro, period) pairs came
# from waveform/chroma autocorrelation peaks, then each was auditioned as a
# 60 s preview (30 s pre-wrap + 30 s post-wrap) and the winner is the pair
# where the music continues across the splice on the right musical phrase
# and one period captures the full song's melodic content. Musical phrasing
# is prioritised over splice silence, so a small residual click at the wrap
# is accepted.
#
# Splice quality at the chosen (intro, period) (50 ms window RMS):
#   BREEZE  intro= 89.2780s  period=199.6790s  ->  -15.6 dB RMS
#   SPLASH  intro=  0.0000s  period=337.9200s  ->  -19.5 dB RMS
#   MAGICAL intro= 59.5160s  period=238.0830s  ->  -12.4 dB RMS
#
# Render durations are auto-derived: (intro + loop) for music_loop, the
# explicit value for the other kinds.
