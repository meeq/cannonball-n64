# Sound IDs to bake into the N64 wav64 payload.
#
# Consumed by cmake/audio-payload.cmake — each row becomes one .wav64 in the
# build tree, dropped into the DFS at ROM-build time.
#
# Columns: id  kind            filename            params
#   id        Z80 sound command byte from src/main/engine/audio/commands.hpp
#   kind      music_loop:    PCM+YM mix; wav64 wraps from end back to `intro`
#             music_oneshot: PCM+YM mix; wav64 plays once and stops
#             fx:            YM-only;    wav64 plays once and stops
#   filename  output basename under audio/raw and audio/wav64
#   params    music_loop:    intro_seconds  loop_seconds
#             other kinds:   duration_seconds
#
# Loop values come from tools/audio-render/measure-splice.py, which scores
# the audible click at the wrap point on the rendered WAV (point step +
# windowed RMS) and finds the (period, intro) that yields a bit-exact
# splice. The MML walker's structural cycle isn't always usable directly —
# YM2151's internal eg_cnt / LFO drift incommensurately, so the audio at
# one structural cycle isn't byte-identical to the next. We pick the offset
# where the YM internal counters coincidentally realign.
#
# Splice quality at the chosen (intro, period) (50 ms window RMS, all bit-
# exact at the splice point):
#   BREEZE  intro=  6.5497s  period= 61.440s  ->  -62 dB
#   SPLASH  intro= 46.7897s  period=122.880s  ->  -87 dB
#   MAGICAL intro=157.2499s  period= 30.720s  ->  -65 dB
#
# Render durations are auto-derived: (intro + loop) for music_loop, the
# explicit value for the other kinds.
